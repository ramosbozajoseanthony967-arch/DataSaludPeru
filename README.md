# DataSalud Perú

## Descripción

Proyecto integrador de curso: Sistema integrado de base de datos segura, automatizada e inteligente para la DIRESA La Libertad.

El proyecto integra SQL Server, MongoDB, Power BI y Apache Spark para gestionar, analizar y visualizar información relacionada con las atenciones de salud.

## Estructura del repositorio

### Automatizacion
Contiene los procedimientos almacenados, triggers y funciones implementados en SQL Server.

### Seguridad
Contiene los scripts relacionados con roles, permisos, copias de seguridad y restauración de la base de datos.

### BI
Contiene los componentes relacionados con Data Warehouse, procesos ETL y dashboard de Power BI.

### BigData
Contiene el notebook desarrollado con PySpark y los análisis de procesamiento de datos.

### MongoDB
Contiene las operaciones CRUD y las pruebas realizadas utilizando MongoDB como componente NoSQL.

### Documentacion
Contiene la documentación del proyecto, matriz de trazabilidad y evidencias.

## Herramientas utilizadas

## Instrucciones de ejecución

### SQL Server

Ejecutar los scripts SQL mediante SQL Server Management Studio en el orden indicado dentro de las carpetas correspondientes.

### MongoDB

Ejecutar el script CRUD mediante MongoDB Shell y verificar las operaciones de inserción, consulta, actualización y eliminación.

### Power BI

Abrir el archivo PBIX correspondiente y verificar los indicadores, visualizaciones, filtros y operaciones de análisis.

### PySpark

Abrir el notebook en Google Colab y ejecutar las celdas en orden para cargar, transformar y analizar los datos.

## Organización

El repositorio está organizado por bloques temáticos para facilitar la ejecución, revisión y trazabilidad de los componentes desarrollados durante el proyecto.
